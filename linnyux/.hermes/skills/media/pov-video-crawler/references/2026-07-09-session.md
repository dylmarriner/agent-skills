### 6. Functions vs Scripts Gotcha (for xargs parallel verification)
`export -f process_url` + `xargs -P sh -c 'process_url "{}"'` **does NOT work** — exported bash functions are invisible to xargs subshells. Use a standalone `.sh` script file with `xargs -P` instead. This is the correct pattern:

```bash
chmod +x /tmp/verify_single.sh
cat /tmp/urls.txt | xargs -P 8 -I{} /tmp/verify_single.sh "{}" /tmp/results.txt
```
