# Android Native Dark Theme Setup

When building a React Native/Expo app with a dark theme, the Android native side defaults to a white background. This reference covers every layer that needs to be set dark to avoid white flashes, white splash screens, or white backgrounds on the auth/login screen.

## Layers to fix (bottom-up)

### 1. Android Theme (`styles.xml`)

**File:** `android/app/src/main/res/values/styles.xml`

The default theme `Theme.AppCompat.Light.NoActionBar` has a white background. Switch to:

```xml
<style name="AppTheme" parent="Theme.AppCompat.NoActionBar">
    <item name="android:textColor">#EEF6F2</item>
    <item name="android:editTextStyle">@style/ResetEditText</item>
    <item name="android:editTextBackground">@drawable/rn_edit_text_material</item>
    <item name="colorPrimary">#070B10</item>
    <item name="colorPrimaryDark">#070B10</item>
    <item name="android:windowBackground">#070B10</item>
    <item name="android:statusBarColor">#050505</item>
    <item name="android:navigationBarColor">#070B10</item>
</style>
```

Key differences from Light variant:
- `parent="Theme.AppCompat.NoActionBar"` instead of `Theme.AppCompat.Light.NoActionBar`
- `android:windowBackground` — the flash before JS loads
- `android:statusBarColor` and `android:navigationBarColor` — system chrome
- `android:textColor` — default text color to avoid white-on-white inputs

### 2. Splash Screen

**File:** `android/app/src/main/res/values/colors.xml`

```xml
<color name="splashscreen_background">#070B10</color>
```

The splash screen drawable references this color. Generated by Expo; verify the color name matches what's in `app.json`.

### 3. NavigationContainer Theme (React Navigation)

**File:** `App.js` or root layout

The `NavigationContainer` has its own dark mode theme. Without it, the container's background is white:

```javascript
import { Theme } from './src/styles/DesignSystem';

const navTheme = {
  dark: true,
  colors: {
    primary: Theme.colors.primary,
    background: Theme.colors.bg,
    card: Theme.colors.bg,
    text: Theme.colors.text,
    border: Theme.colors.border,
    notification: Theme.colors.primary,
  },
  fonts: {
    regular: { fontFamily: 'System', fontWeight: '400' },
    medium: { fontFamily: 'System', fontWeight: '500' },
    bold: { fontFamily: 'System', fontWeight: '700' },
    heavy: { fontFamily: 'System', fontWeight: '900' },
  },
};

// Then use it:
<NavigationContainer theme={navTheme}>
  <AppNavigator />
</NavigationContainer>
```

### 4. Root View Background

The root `<GestureHandlerRootView>` or outermost `<View>` should also have the dark background:

```jsx
<GestureHandlerRootView style={{ flex: 1, backgroundColor: '#070B10' }}>
```

### 5. Stack Navigator cardStyle

For `@react-navigation/stack`, each stack screen may flash white during transitions. Set:

```jsx
<Stack.Navigator screenOptions={{
  headerShown: false,
  cardStyle: { backgroundColor: '#070B10' }
}}>
```

## Debugging

If any screen still shows white:
1. **ADB check**: Run `adb shell dumpsys window | grep mCurrentFocus` to confirm the app is active
2. **Hermes JS bundle**: Verify `index.android.bundle` exists in assets/ and is the latest build
3. **Network security**: If using HTTPS with self-signed certs, add `network_security_config.xml` and reference it in `AndroidManifest.xml` — a TLS failure can show a blank white screen before the error dialog
4. **Logcat for RN errors**: `adb logcat -d | grep ReactNativeJS` will show JS-level crashes that manifest as white screens
