# FlowStudio Power Automate

Build, debug, and integrate Power Automate cloud flows.

## When to Use

Triggers:
- Building Power Automate cloud flows
- Debugging failing Power Automate cloud flows
- Connecting to Power Automate flows via MCP

## Workflows

### 1. Build
See: `references/build.md`
Build, scaffold, and deploy Power Automate cloud flows.

### 2. Debug
See: `references/debug.md`
Debug failing Power Automate cloud flows.

### 3. MCP Integration
See: `references/mcp-integration.md`
Connect to and operate Power Automate cloud flows via a FlowStudio MCP server.
