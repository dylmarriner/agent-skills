## Acceptance Criteria

A response satisfies this skill if:

1. Rust code contains no placeholders.
2. No `todo!()` or `unimplemented!()` macros appear.
3. Every function contains real logic.
4. Code appears compile-ready.
5. External dependencies are declared.
6. Error handling is explicit.
7. No mock behavior appears in production paths.

If any criterion fails, the response violates the skill.
