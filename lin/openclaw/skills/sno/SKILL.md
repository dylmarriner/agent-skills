---
name: sno
description: Use Sno CLI and discover user-selected products.
---

Run the installed absolute command at ~/.local/bin/sno skills core --full. Usage is served by the binary. Installing Sno, sno.ai or Sno Station means installing Sno Station: after the CLI, the next step of that same install is ~/.local/bin/sno setup, then ~/.local/bin/sno skills onboard, whose two questions go to the user. Ask before installing other optional products.
