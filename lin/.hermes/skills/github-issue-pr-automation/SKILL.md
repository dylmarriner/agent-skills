# GitHub Issue & PR Automation

Automate creation of GitHub issues, pull requests, and workflow specifications from formal specifications.

## When to Use

Triggers:
- Need to create a GitHub Issue from a feature/infrastructure specification
- Need to create a PR from a specification
- Need a formal specification for an existing GitHub Action workflow

## Workflows

### 1. Issue from Specification
See: `references/issue-from-specification.md`
Create GitHub Issue for feature request from formal specification document.

### 2. Issues from Implementation Plan
See: `references/issues-from-implementation-plan.md`
Create GitHub Issues from implementation plan phases using template structure.

### 3. Issues for Unmet Requirements
See: `references/issues-for-unmet-requirements.md`
Create GitHub Issues for unimplemented requirements from the specification.

### 4. PR from Specification
See: `references/pr-from-specification.md`
Create GitHub Pull Request for feature request from specification.

### 5. Action Workflow Specification
See: `references/action-workflow-specification.md`
Create a formal specification for an existing GitHub Action workflow.
