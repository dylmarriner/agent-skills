# custom-memory-mcp

Use this skill for the Robbie custom-memory MCP server.

## Purpose
This MCP server provides persistent memory and project context tools:
- add_preference
- create_or_update_project
- add_project_document
- log_decision
- add_idea
- record_troubleshooting_fix
- save_workflow_checkpoint
- add_lesson_learned
- get_project_context
- global_brain_search

## When to use
Use this skill when the user wants to:
- inspect the server and its tools
- add or update memory records
- recall project context before a task
- store decisions, preferences, lessons, ideas, and troubleshooting notes
- connect the memory server to an ongoing project workflow

## Operating steps
1. Identify the current project or task context.
2. Check for existing project context or relevant memories before acting.
3. Add or update preference, decision, lesson, or checkpoint records as needed.
4. Search memory before major work to avoid repeating rejected ideas.
5. Keep writes concise, structured, and project-scoped.
6. Prefer existing records over creating duplicates.

## Good habits
- Record user preferences as soon as they are stable.
- Record decisions when they affect future work.
- Record lessons when a mistake is corrected or a workflow improves.
- Record checkpoints before pausing a multi-step task.
- Use global search before complex tasks that might reuse prior context.
- If the persistent memory store is near capacity, compact first: remove or shorten low-value/stale entries before adding a new durable note.
- Keep saved memory entries short and high-signal to avoid hitting the store limit.

## Notes
This skill describes how to use the Robbie custom-memory MCP server; it does not replace the server itself.
